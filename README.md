# Datheon Data Analytics & Power BI Internship

A two-task data analytics portfolio project completed as part of the Datheon Data Analytics & Power BI Internship. The project demonstrates data cleaning, exploratory data analysis, business insights, dimensional modelling, DAX, and interactive Power BI dashboard development using the Sample Superstore dataset.

## Project Overview

This repository contains two analytical projects built around retail sales data.

### Task 1 — Python Exploratory Data Analysis (EDA)

An exploratory analysis of the Sample Superstore dataset using Python to identify sales trends, profitability patterns, regional performance, and product-level insights.

**Tools:** Python, Pandas, Matplotlib, Jupyter Notebook

### Task 2 — Power BI Executive Sales & Profit Dashboard

An interactive, multi-page Power BI dashboard designed to evaluate sales performance, profitability, product performance, and regional business results.

**Tools:** Power BI Desktop, Power Query, DAX

## Repository Structure

- `Task_1_Superstore_EDA/` — Python EDA, dataset, analysis outputs and visualizations.
- `Task_2_PowerBI_Executive_Dashboard/` — Power BI dashboard, report export, dataset and screenshots.
